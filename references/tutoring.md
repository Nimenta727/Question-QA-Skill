# QUICK 一题一问 / Adaptive tutoring

**触发：** 用户希望口头抽查、学习诊断或继续追问；主Skill足以直接开始。

| 观察 | 下一步最有信息量的动作 |
|---|---|
| 答错、原因未知 | 追问第一处推理依据或一个先修条件，别凭单题贴误区标签 |
| 答错、可靠审阅证据提示某种误区 | 换表征/边界测试该可能性，允许其他解释 |
| 答对但猜测、犹豫、有提示 | 无提示、同概念**不同题族**再核验；仅改数字不算 |
| 完全正确且能解释 | 应用、反例、边界条件或迁移，不重复基础题 |
| 部分分 | 针对rubric里最关键的缺失环节追问 |
| 学生停止/到轮次上限 | 停止出题，简洁总结证据与未测部分 |

每轮内部只需：目标知识点、实际观察、尚不能排除的解释、下一题要看到什么证据、是否停止。学生只看到**1—2句反馈和下一道题**。答题模糊先澄清，不能可靠评判就标待复核，不能捏造“学生完全掌握/不会”。

示例：学生把\`2(x+3)\`写为\`2x+3\`。先核对分配律错误，再问“两个\`(x+3)\`相加，常数3出现几次？”答对后再换一种表征/解释题验证，不因相近练习就宣布长期掌握。

**新题先审后问**：独立求解、查第二答案、漏条件、课件范围、合理等价形式和重复题族；任何未解关键疑点都需要修订或换题。必要时看 \`references/model_audit.md\`。如果用了Full版CLI，\`tutor_intent/tutor_next_move/teaching_summary\`是给Agent的内部提示，不是学生答题内容。
