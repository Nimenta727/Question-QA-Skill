# 独立第二队列：ASSISTments 2015 真实数学练习验证（2026-11-20）

## 结论
使用独立数学学习样本后，现有 v0.2 的形成性诊断指数**仍未显示优于简单历史成绩基线的预测能力**。跨知识点测试 AUC 为指数0.6202，学生历史0.7102。这里评的是下一次作答排序，不是潜在掌握或考试效标。

## 来源、使用条款与数据审计
- 官方来源：[ASSISTments 2015 Skill Builder](https://sites.google.com/site/assistmentsdata/datasets/2015-assistments-skill-builder-data)，遵循 [ASSISTments 研究数据使用条款](https://sites.google.com/site/assistmentsdata/termsofuseforusingdata)，不得重新识别匿名学习者。
- 可重现镜像：[pyKT](https://github.com/pykt-team/pykt-toolkit)，固定提交 ccbaf37b07e3e7ff7b2415475b2faacb967d54ea，源文件 Git blob SHA1 f6b86c94e2a90316efd4bfd24655526919a817b0。
- 原始文件有708,631行、19,917名匿名学习者、100个题集。按SHA256(seed=2026,学生ID)从全部学生固定挑出1500人；其中1495人有有效记录，合计50,540条有效作答。抽样ID对应行还剔除了1818条无效或无法二值评分的记录。
- 学生整体拆分：训练874、验证330、测试291。留出测试的**有效预测**来自280名学生，共5728次答题。
- 原文件只有 user_id、log_id、sequence_id、correct 四个字段；log_id只用作顺序，不当作日历时间，sequence_id是题集/技能序列ID，**不是唯一具体题目ID**。认知层次没有独立标注。程序保守使用“未知同一题族”和占位日期，防止重复接触伪装成独立题或跨日保持证据。

## 防止未来信息泄漏
使用历史序列逐题生成对当前下一次回答的预测，预测之后才加入该回答；全局与概念先验只取训练学生。任何验证/测试学习者均不能出现在训练数据里。没有对留出测试集调阈值或训练 BKT/IRT。

## 真实结果

| 模型/信号 | 验证集 AUC（6566次） | 测试集 AUC（5728次） |
|---|---:|---:|
| 全局先验 | 0.5000 | 0.5000 |
| 题集先验 | 0.6155 | 0.6606 |
| 学生该题集历史平均（带先验平滑） | **0.7061** | **0.7102** |
| v0.2 诊断指数 | 0.6197 | 0.6202 |

知识点内部宏平均AUC：验证集历史0.5899、指数0.5888；测试集历史0.5741、指数0.5620。

指数减历史基线的**跨题集 AUC 差值**：验证集95%学生簇Bootstrap区间 [-0.0992,-0.0723]；测试集 [-0.1003,-0.0736]。**同题集宏平均差值**：验证集 [-0.0061,+0.0365]、测试集 [-0.0152,+0.0294]，均包含零。100次固定随机种子的学生簇重抽样，区间为探索性估计。

测试样本中“暂定较强”标签有 **0例**：不是零误判，而是数据缺少可信的独立题族、认知层次与跨日复测证据，不能检验该标签的敏感度/特异度。

## 研究解释
- 此评测使用**真实数学练习序列预测下一题**，此前 FORGET-SE 使用**周测预测独立期末考试结果**，预测目标不同，AUC不可直接跨数据集比较。
- 当前指数在未知具体题目的情况下只保留近似“该题族最近证据”，自然损失了历史统计信息；不能归因于所有现实场景的算法质量。
- 无法证明自适应选题提高学习效果；那需要前瞻性、恰当授权与伦理监督下的对照研究。
- 原始数据受研究使用条款限制，本仓库不复制任何学生原始CSV、个人级日志或题干。
