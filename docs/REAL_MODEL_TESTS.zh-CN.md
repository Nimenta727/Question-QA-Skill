## 测试前必须具备的条件

- 只用有权使用并真正读取的课件：记录课程版本、章节/页码、核对过的知识断言、所需先修知识。没获得授权则改用明确标注的**合成通用题**，不能冒称老师原题。
- 题族按照不同推理机制/表征划分，**换数字不算独立题族**。提前制作正确答案全集、等价解、歧义与缺陷标签。
- 命题与审阅分开：审核者先盲解，再看作者答案。记录模型名称/版本、提示词、配置/种子（有则记录）、题目和来源 SHA256、审核意见、修订及再次审题。**同模型自审不能统计成独立审题**。
- 尽可能由至少两名合格评阅者盲审与独立标注，记录分歧并单独裁决；开发集与最终留出集要按课程/知识点/题族（合规真人研究还要按学习者）隔离，先冻结后测评。FORGET-SE、ASSISTments2015 的旧测试集不可再冒充全新留出集。

## 逐项执行与交付规范

1. **预注册方案：** 先固定样本选取、样本量依据、缺陷分类、主要指标、置信区间方法和拟定的合格阈值；不要看完测试结果再修改阈值。小规模试点只能发现问题，不足以认证总体准确率。
2. **准备答案标准：** 用合成或获授权的题构造有缺陷和无缺陷两类样本，合格专家先独立盲标；保留裁决前的分歧。
3. **冻结模型配置：** 记录 Skill 的 Git commit、模型及版本、加载的 references、源文档片段、提示词、审核者是否真正独立、可用工具与随机设置。**离线 Python 脚本运行不算大模型测试**。
4. **实际命题与审题：** 记录盲解→逆向质疑→来源验证→拦截/放行→修题→复审过程；答案/来源存在未解决问题时不得向学生放行。
5. **追问对照：** 同一组经过许可或合成的学生推理案例同时进入自适应与固定题序，并尽量让专家不知道所属组；复播结果只能评价策略决策，不能直接证明真实学习收益。
6. **统计和报告：** 明确 TP、FP、FN、TN、各类别漏检、独立评分差异、置信区间、运行时间和 Token；区分“题目正确”“问得是否准确”与“真实学习是否提升”。
7. **提交结果：** 复制 [报告模板](validation/REPORT_TEMPLATE.md)，填写准确的分子分母、日期、Git 版本、模型、审核类型、失败项和课程来源授权状态。公开时只能放无个人信息的聚合统计。

## 必须拦截的失败

有错误答案、第二正确选项、伪造出处、未审核 rubric 或重要评阅争议的题目，**不允许作为已审核题放给学生**。未来对版本级质量作出声明，必须先冻结验收阈值和统计区间。目前没有任何真实命题、审题正确率或教学增益达标认证；**CI 全绿只能证明工程测试**。
