# AI 教学质量评估协议（人工审阅模板，不是已完成的人体实验）

目标：单测能发现“选错追问分支、泄漏答案”，但不能独立判断 AI 生成的问题是否真的帮助学生理解。本协议用于未来在取得必要授权的条件下进行独立评阅；目前**尚无该协议下的真人评估结果**。

## 每轮人工审阅的六个标准（每项 0 / 1 / 2）

| 标准 | 0（不满足） | 1（部分满足） | 2（满足） |
|---|---|---|---|
| 课程对齐 | 伪造出处、超纲 | 基本对齐但定位不清 | 知识点、条件和来源可核实 |
| 内容准确与公平 | 错解、误导或多义不处理 | 可修订的模糊 | 解法可靠，等价答案和边界明确 |
| 证据与错因克制 | 一错就宣称“不会” | 有提醒但仍过度归因 | 区分可观察表现与尚未核实的误区 |
| 追问区分度 | 直接重复题干或泄漏答案 | 有变化但无法排除猜测 | 不同题族/表征，成功证据明确 |
| 反馈的教学价值 | 空洞鼓励或羞辱 | 部分指向错误 | 指出具体可修正步骤，简短尊重学生 |
| 节奏与闭环 | 一次多问、强迫继续 | 基本单轮 | 一题一问、答后再问、按请求停止并总结 |

## 评估样例与流程

- **猜对但不确定**：是否安排无提示的另一题族，而不是宣称“掌握”？
- **错误但没有可靠错因**：是否先索取推导，而不是编造错误心理？
- **一部分 rubric 正确**：是否只针对遗漏部分提问？
- **已答对带解释**：是否在课程范围内设置迁移，而不是只改数字？
- **同题连续正确**：是否警惕重复暴露、跨日保持未验证？
- **课件不足/题库耗尽**：是否清楚标注内容来源、先检验新题再给学生？
- **学生主动停止**：是否立即给出证据克制的总结？

试验时先由真实课件与经审校rubric建立独立参考材料，再将同一合成或获授权的匿名学生回答交给两个互相不看对方评分的评阅者。记录每项0/1/2及错误原因，先冻结独立初评，再协商分歧。比较新旧 Skill 时应预先固定题目范围、模型设置、轮次和主要指标，避免根据结果调整规则，且不得把模型自动自评当作独立证据。

任何需要实际未成年人回答、教师资料或课堂招募的实验，都应由机构负责人处理适用许可、知情同意、必要的监护同意、数据保护、退出与申诉。此仓库不会自动组织真人试验。不能把 CI 单测通过率转述成教学有效率。
