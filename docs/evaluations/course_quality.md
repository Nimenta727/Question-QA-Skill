# Study A: Real-course question quality / 真实课程命题质量

**NOT RUN** · RM-01, RM-02, RM-12.

1. **Rights and blueprint:** Obtain permission to use actual C-programming and, where feasible, a non-programming course. Record source version, section/page, SHA256, knowledge assertion, prerequisites, target reasoning, allowed alternate answers and rubric in a protected registry. Do not upload restricted materials.
2. **Frozen sample:** Select distinct reasoning families and course chapters before running the model. Freeze the source list, sample plan, Skill commit, model/configuration, generation prompts and acceptance thresholds. Changing numbers is not a new family.
3. **Actual model run:** Have the model read the authorized course and use the Skill to author questions. Record case IDs, source hashes and invocation metadata in private storage.
4. **Independent blind grading:** At least two qualified reviewers solve each item *before* viewing the proposed answer, then check alternative solutions, ambiguity, source citations, fairness, distractors and subjective rubrics. Preserve disagreement and adjudication.
5. **Metrics:** Acceptable-item rate = independently adjudicated sound and sourced items / all adjudicated generated items; source verification = supported source claims / source claims checked. Report unresolved cases, course and family counts, confidence/cluster assumptions, reviewer agreement and specific error categories.
6. **Exit gate:** No real accuracy claim until actual model runs and independent reviews are documented. Never release disputed questions as verified.
