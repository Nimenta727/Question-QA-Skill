# 学习诊断实证评测（2026-11-20）

**结论：现有 v0.2 启发式诊断指数尚未在真实外部效标测试中证明优于简单成绩基线。暂不加入 BKT/IRT。**

## 数据、伦理与样本
- 来源：[FORGET-SE](https://github.com/alyssa-sha/FORGET-SE)，上游 README 声明已获得研究参与者同意、匿名化并以 CC BY 4.0 授权；固定上游提交 `012f4ca56155140f5e5017dd336e4f9a5c5f249c`。
- 周测 10,873 行，其中 729 行为 0–1 之间的部分得分，不强行改成二分类。
- 期末文件有 186 行，其中 18 个匿名 ID 重复且成绩矛盾。为避免关联错误，完全剔除这些冲突 ID，得到 **150 个有效学生 ID**。
- 分组（由学习者 ID + seed=2026 的 SHA-256 哈希决定）：训练84、验证36、测试30；测试共 **279 个可评估的学生×知识点期末答题结果**。
- 历史 log_id 是去标识化排序号，不是可确认的复习日期；没有经过独立审校的题目认知层次，因此不能检验 v0.2 的延迟复测和深度迁移掌握门槛。

## 方法
- 训练组期末得分用于构建全局/知识点先验；验证和测试学生的期末答案不得流入特征或先验。
- 同一个学生的周测历史用来预测其独立期末考试在对应知识点的答题结果。期末成绩只是**外部效标**，不是真实潜在知识状态。
- 比较全局先验、知识点先验、周测全部均分、最近三次周测均分以及 v0.2 诊断指数。
- 同时报告跨知识点 AUC、知识点内部宏平均 AUC，以及按学生抽样的200次 Bootstrap AUC 差值95%区间。v0.2 指数并未校准成概率，所以只对它报告 AUC。

## 结果（独立测试集）

| 方法 | 跨知识点 AUC | 知识点内部宏平均 AUC |
|---|---:|---:|
| 全局先验 | 0.5000 | 0.5000 |
| 知识点先验 | 0.7572 | 0.5000 |
| 周测全部均分 | 0.6998 | 0.5509 |
| 最近三次周测 | 0.7352 | 0.5538 |
| **v0.2 指数** | **0.5149** | **0.5535** |

诊断指数减去全部周测均分的跨知识点 AUC 差值95%学生簇区间 **[-0.2396, -0.1377]**；同知识点内部差值区间 **[-0.0116, +0.0155]**，包含零。没有充分证据支持 v0.2 优于简单历史成绩基线。

验证组跨知识点 AUC：全局0.5000、知识点先验0.7736、全部均分0.7203、最近三次0.7509、指数0.5351；知识点内宏平均 AUC：全部均分0.5680、最近三次0.5909、指数0.5830。

测试组和验证组都没有能够满足 v0.2 `tentatively_strong` 标签的独立、延迟和高层次证据，**0 个“较强”判断不能解释为诊断错误率为零**。

## 不能得出的结论
- 没有经过认证的潜在掌握标签，因此不能据此报告“已掌握误判率”或精确掌握概率。
- 课程、年龄、学科及测试形式不同，不能把这份大学课程成绩直接外推到初高中。
- 历史日志中没有真实的随机选题或曝光概率，不能验证自适应选题能否因果性改善学习。
- 即使有 AUC 改进，也必须在第二份独立数据、真实间隔复测、审校的知识点和认知层次映射上重复验证。
- 不能使用当前测试集调整阈值后再把它当成未见过的数据汇报。

## 复现
[成功的真实数据评测工作流](https://github.com/Nimenta727/Question-QA-Skill/actions/runs/44743252876)。自动下载并校验固定版本的公开数据，临时文件只留在运行环境，上传的 artifact 只有汇总 JSON（保留14天），不包含任何学生原始记录。

```bash
python3 scripts/evaluate_forget_se.py --weekly /path/forget_se.csv --exam /path/exam.csv --seed 2026 --bootstraps 200
python3 scripts/evaluate.py /path/answers.csv --format generic
```

## 下一步决策
1. 先找审校的题族、认知层次、时间间隔和第二个真实学习队列。
2. 将“证据是否充分/下一题如何追问”与“未来答对概率预测”分离，后者必须独立标定。
3. 对简单基线、校准指标、漏判/误判和不同学科/人群稳定性做预注册比较。
4. 只有达到样本与数据权限要求、能在未参与调参的测试集上稳定胜过简单基线，才考虑单独开展 BKT/IRT 试验；默认 Skill 不增加额外模型调用成本。
