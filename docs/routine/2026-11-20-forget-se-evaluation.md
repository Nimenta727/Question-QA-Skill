# 2026-11-20 — FORGET-SE 真实外部效标验证 / Real external-criterion harness

## 本次改动
- 新增 scripts/evaluate_forget_se.py：使用 FORGET-SE 的真实周测数据与独立期末考试 KC1–KC10 结果，按学生分离训练/验证/测试，比较诊断指数与简单基线。
- 周测含 0–1 部分得分，以真实分数进入诊断统计；期末只有0/1作为外部效标。考试结果仅在训练学生用于概念先验，验证/测试结果严格留作评估。
- 提供学习者簇 bootstrap 的 AUC 差值置信区间，避免仅凭 AUC 点估计宣布提升。
- FORGET-SE 时间已匿名化，认知层次未标定；不会伪造跨日期和高阶成功证据，因此该数据不能独立验证“暂定已掌握”标签。
- 严格不保存或输出个人级作答结果、不将原始数据提交仓库。版权归原始研究作者，使用参照其 CC BY 4.0。
