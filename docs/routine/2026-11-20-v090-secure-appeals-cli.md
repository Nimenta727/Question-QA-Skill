# 2026-11-20 — v0.9.0 安全审阅与HMAC审计链CLI集成

## 修改内容
- qa.py新增audit-init、audit-verify、audit-checkpoint，初始化时必须持有独立管理员凭据，并只允许绑定未有历史申诉的新学习状态；生成独立0600审计密钥，不将HMAC密钥放入状态/仓库。
- 启用审计后，appeal-open必须提供密钥并先验证既有审计链，提交申诉后追加HMAC记录；appeal-resolve必须提供绑定登记簿的**有效本地审阅者能力凭据**及审计密钥，撤销/错误身份不能靠--reviewer-confirmed绕过。
- 本地凭据验证后记录审阅ID及认证方式，旧未开启保护的学习状态继续兼容v0.8自声明流程但明确注明未认证；audit-verify可结合单独保管的checkpoint检测整个历史链回滚。
- 对已启用审计的学习状态，回滚需要额外--acknowledge-audit-rollback，删除需要额外--acknowledge-audit-deletion，避免用户误以为安全账本不会被自己恢复/删除。
- 输出不包含管理员密钥、审阅者token、学生答案原文；密钥与checkpoint保管责任属于使用者，不能由软件验证真人身份。
