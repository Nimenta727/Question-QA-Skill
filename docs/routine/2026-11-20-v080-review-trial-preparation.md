# 2026-11-20 — v0.8.0 双审阅者盲评实验执行准备器

## 本次修改
- 新增 scripts/reviewer_trial.py：研究负责人提供**不包含学生答卷**的匿名case_id、每案例评分维度数，以及预先冻结rubric与外部授权/同意确认状态；若要标记为真实授权研究而授权未确认则直接拒绝。
- prepare 在受控本地目录生成私有manifest和分别乱序的A/B审阅者任务文件，互不包含对方打分，不包含学生姓名/身份或题目答案，部署端需另行提供受权限保护的真实材料。
- freeze 仅接收两位审阅者均已完成的第一轮独立评分表，逐项验证与预设rubric完全一致，无缺失/重复案例，并输出只有汇总一致率、置信区间及首次冻结SHA256的文件；无个人级答卷/ID/评语。
- 输入上的authorized和study_type均由研究负责人**自行声明**，不构成真实伦理审查、法定监护许可或盲评独立性证明；第三人仲裁必须在第一轮冻结之后通过外部安全流程完成。
- 未收集学生真实数据、未接触真人审阅者、没有实施任何真人试验。CI只验证合成流程，不能声称模型评分已被真人试验确认。
