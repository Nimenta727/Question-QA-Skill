# 2026-11-20 — 第二独立真实数据评测适配器 / Independent ASSIST2015 cohort

## 本次改动
- 新增 scripts/evaluate_assist2015.py：与首次 FORGET-SE（软件工程周测/期末）完全不同的 ASSISTments 2015 数学练习日志，面向真实下一次作答预测。
- 预注册算法：两次顺序读取本地源 CSV，固定 seed=2026，按匿名用户 SHA256 排序抽样最多2000个；训练/验证/测试按学生整体隔离；每题预测只用此前记录；比较全局先验、知识点先验、个体历史与当前诊断指数。
- 增加知识点内部宏 AUC、按学生 bootstrap 的预测差值区间，防止只凭不同题集本身难度判优。
- 官方源仅有 user_id/log_id/sequence_id/correct 四列；**不含试题 ID、认知层次或真实复测日期**。不能把多次同技能回答编造为独立题族，故使用相同未知题族和日期占位，禁止以此宣称深度/延迟掌握验证成功。
- 数据只允许本地研究使用，受 ASSISTments 来源使用条款限制，不把原始行、学生ID或题目文本存入仓库或报告。
