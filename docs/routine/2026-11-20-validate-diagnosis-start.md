# 2026-11-20 — 开始真实诊断验证 / Begin diagnostic validation

## 本次改动
- 新增零依赖评估程序 scripts/evaluate.py：支持普通答题CSV和本地ASSISTments 2009导出，按学生隔离训练/验证/测试，按记录顺序滚动预测（绝不提前读取待预测答案）。
- 指标包括 AUC、Brier、Log loss、10箱ECE、0.5阈值准确率；将 v0.2 指数视为非校准指标，只报告排序能力AUC。
- 单独审计暂定强、证据不足、需复习等判断的下一次作答错误率与Wilson区间、Bootstrap置信区间，以及可否开展进一步参数化模型研究。
- 不上传学生原始答题数据，不输出用户标识，也不将历史试题曝光造成的选择偏差误判为因果效应。

## 下一步规划
1. 加入包含数据泄漏、未来标签、少量样本、同题重复等边界情形的自动测试。
2. 用公开、授权的真实作答数据运行；未获得合适数据或标签时必须明确“尚未验证”，不能用生成数据冒充实证。
3. 再根据性能及置信区间决定是否有必要单独实验经过标定的 BKT/IRT。
