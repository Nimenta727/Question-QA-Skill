# 2026-11-20 — v0.9.0 独立专家参照评分分析器 / Frozen dual-review versus expert rubric

## 修改内容
- 新增 scripts/reviewer_pilot.py：保留既有 reviewer_trial.py 双评阅独立首轮流程，读取冻结汇总、原A/B评分包及匿名独立专家参照评分。
- 强制校验首轮评分包 SHA256 与冻结时哈希一致；案例ID、每题评分维度、评分等级必须与预先固定的研究manifest相符；专家参照是另外独立提交的完整评分包。
- 统计评分者A和B分别与专家参照一致率、绝对偏差、两评阅者一致率、双方一致却与专家评分不同的条目数，以及案例级bootstrap不确定区间。
- 输出只含汇总指标和专家参照内容哈希，不含原答案、任何具体评分条目、匿名案例ID或个人信息。真正专家资格、参照答案是否正确、真人授权与盲评独立性均无法通过代码验证。
- 所有实际研究数据须在机构授权、监护/学生同意及访问控制下外部提供；本仓库仅交付软件工具与合成回归。
