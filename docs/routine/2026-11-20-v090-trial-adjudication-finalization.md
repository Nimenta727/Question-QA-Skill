# 2026-11-20 — v0.9.0 双盲研究首轮冻结后的第三方争议仲裁

- scripts/reviewer_trial.py新增finalize命令：要求提供首轮freeze汇总收据及原封不动的A/B评分包，先用SHA256重算证明评分输入与冻结时一致，不允许先看仲裁再修改原始评阅。
- 决议包C只允许对两位审阅者有分歧的(case_id,criterion_index)逐项决议；不得改动一致项、遗漏争议或重复决议；理由代码受控而不含学生原答。仲裁完成后输出A/B匹配数、第三种中间分选择数与匿名案例总数，**不输出任何case_id或具体答案**。
- 结果只说明输入文件与已冻结评分是否一致、争议是否完整处理，不证明C是真人、与A/B真正独立，或评分正确；实际真实研究仍需机构授权和参与者同意，不得用合成样本替代实测。
- 首轮冻结与仲裁完成之间没有修改已经发布的统计对象，保留先验终点和现实权限限制。
