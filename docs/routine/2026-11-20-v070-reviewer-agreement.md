# 2026-11-20 — v0.7 双审阅者一致性研究工具

## 本次改动
- 新增 scripts/reviewer_study.py：对匿名成对评分记录计算逐标准一致率、整题一致率、二次加权 Cohen Kappa、平均分歧、争议及待仲裁数量；可按整份学生答卷（case）做 bootstrap 一致率区间。
- 明确输入只有0/0.5/1评分，两个评分者必须具有相同rubric长度，仲裁分数不可修改原本已一致的条目；输入案例ID仅在内存中检查唯一性。
- 输出只包含聚合数据，不包括案例ID、学生回答、审阅证据、审阅者身份，Kappa在没有任何预期分歧的常数情形返回null而非假造1。
- 数据类型来自调用者自声明，程序不能确认真人参与、双盲独立性、事实正确性或评分公平性；真实实验还未开展。

## 下一步规划
1. 补充合成测试，覆盖Kappa边界、评分冲突、重复ID及聚合隐私。
2. 制定真实双人审阅研究协议，明确同一rubric、盲法、独立参照答案、争议与申诉处理。
3. 发行v0.7.0之前核实跨平台测试与可追溯不可变Git Tag。
