# 2026-11-21 — v1.1 模型逐题严格审计验证器

## 本次改动
- 新增 scripts/model_audit.py，把题目严格审计变为**命题者和另一个模型审阅回合分开**的结构化协议：先生成全部未通过的空白模板，再由独立审阅模型逐题填写并接受 fail-closed 程序校验。
- 每题必填九项带实质依据的判断（课程来源与范围、独立解答、正确答案及等价形式、题干条件、多项干扰项/开放题rubric、诊断价值、认知层次、公平性、题族独立性）；单选必须逐个解释3个错误选项，开放题逐项审查rubric。
- 课程来源模式绑定具体UTF-8课件抽取文本的SHA256及逐字源引文，缺少匹配的引文或仍把original-example伪装教师课件即阻止通过；通识练习只允许明确标记general_practice，不可冒充课程题。
- 检查不同审核ID的**自声明**、题库哈希绑定、客观题审阅模型独立答案与题库一致、未处理警告与风险、任一“uncertain/failed”即整体阻止，输出不会泄漏题干及答案。
- 明示程序**并没有调用LLM**，填表必须由实际独立运行的审核模型完成；格式通过不等于语义真实、实名身份独立或有教师审核，正式高风险考试仍要有合格人工复核。

## 下一步规划
