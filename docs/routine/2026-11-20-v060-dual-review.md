# 2026-11-20 — v0.6 双审阅者独立答卷评估 / Two-reviewer assessments

## 修改内容 / Changes
- 新增 scripts/assessment_engine.py，提供正式的 JSON 契约：两位不同审阅者独立按 rubric 对照学生回答，每条必须记录分数、具体证据、反馈和**出现在真实学生答卷中的原文引用**。
- 逐项核对评分标准并计算精确一致率、分歧项及分数差值；如果审阅者存在分歧，必须提供**第三位不同审阅者**的逐项仲裁，否则不提交分数也不消耗 pending 问题。
- 引用可被程序检查为答卷中的真实子串，但这不等于语义正确性证明；审阅者身份与独立性目前由输入自我声明，不是加密证明。
- qa.py answer 新增 --independent-reviews @reviews.json 和 --adjudication @decisions.json，兼容旧版 --score 和 --rubric-judgments；同样仅把数值分数与一致率/分歧数存入本地状态。
- 新增 --response-file，从本地私有文件读取答卷以避免学生文本出现在命令行历史及进程参数中。状态文件仍绝不存原文，教师负责妥善保护本地答卷文件。

## 下一步规划
1. 添加安全/仲裁/隐私/旧命令兼容回归测试，确保无仲裁争议绝不落盘。

3. 更新跨系统 CI 和发行方式、补中文英文说明。
