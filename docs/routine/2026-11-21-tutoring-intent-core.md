# 2026-11-21 — 恢复教学主线：轻量追问决策引擎

## 本次修改
- 新增 `scripts/tutor_core.py`：根据当前会话的作答得分、猜测/提示、可核验的误区标签、先修知识点和候选题元数据，输出 AI 可以直接执行的下一步教学意图。
- 细分基线、先修修复、解释追问、跨题族确认、迁移挑战、结束总结及题库耗尽后生成待审核新题七类决策，不擅自声称学生已经掌握。
- 依据候选题的概念、认知层级与题族，标记“适合此诊断目标”或“需要审阅/创作更好的变式”，避免只凭原选题分数声称追问恰当。
- 输出**不包括**正确答案、评分rubric、学生原话或个人信息；仅保留简短教学状态和下一问题的目标。脚本不负责自动构造未经验证的AI题目。
- 原有`diagnosis.select_item`和用于外部真实数据研究的旧指标未改动，避免在已暴露的留出集上调参。

## 下一步规划

2. 加入覆盖猜对、基础错误、误区不确定、同题族复述、迁移不足和提前结束的合成场景评估。
