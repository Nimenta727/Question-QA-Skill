# 2026-11-21 — 教学决策输出贯通既有QA流程

## 本次修改
- 在`qa.py next`增加`tutor_intent`，随每一道已核验题目返回教学动作、希望检查的证据、题目是否适合本轮教学目标，而不曝光答案/rubric。

- 在`qa.py report`和问题预算结束时提供`teaching_summary`：当前会话知识点覆盖、独立题族数、不确定证据和未测内容；不冒充标准化掌握概率。
- 题库耗尽时新增供AI命题使用的有条件提示，而不是自动编造未审核题目。仍按原`adaptive_engine`选题，不修改已评测的v0.2指标。
- 不改原有状态格式，新增输出都为可选字段；既有安全/审计/存储代码保持不动。
