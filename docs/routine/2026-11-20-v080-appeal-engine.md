# 2026-11-20 — v0.8.0 评分申诉与纠错状态引擎

## 本次修改
- 新增 scripts/appeals.py：支持每次作答唯一 event_id（历史记录可按索引迁移）、一个作答只能有一项未解决申诉；申诉存储原因分类、申诉ID、事件ID、处理状态、时间和纠正前后分数。
- 纠错需明确声明独立复核者已确认，且区分 uphold 和 correct；主观题已有逐项分数时必须给出一致的逐项新分，不能只改总分；客观题只能在0/1之间修正。
- 修正后将评分事件更新成最终有效分供诊断和复习报告重算，同时申诉日志保留更正前后分数；满分后清除旧误区标签，防止旧错因继续误导学生。
- 不持久化姓名、学生原始回答或自由文本审核意见；审阅者确认是自声明，不是身份/专业资质认证。
