# 2026-11-20 — v0.9.0 HMAC关联评分申诉审计链 / Tamper-Evident Appeal Ledger

## 修改内容
- 新增 scripts/audit_ledger.py：以不保存在学习状态文件中的独立32字节密钥，对每次打开/处理申诉的完整必要元数据和对应有效评分进行HMAC-SHA256，记录递增序号、上一条MAC和当前MAC。
- 校验器逐条验证顺序、MAC链和当前申诉快照的精确对应关系，发现已决议的历史分数被直接改写、审计条目删改/换序等不一致时直接拒绝声称验证通过。
- 新增外部可留存的签名式checkpoint收据（包含审计头、链长度和HMAC），可检测整个学习状态被替换成更旧的**合法旧快照**。注意收据必须独立、异地保存，不能跟着旧状态一起被覆盖。
- 这里是**防篡改可检测**而非“不可修改”：拿到审计密钥的攻击者可重算HMAC，删除本地状态与所有收据也能破坏证据。未保存外部收据时不能检测整条链被旧版合法链替换。
- 初始化只适用于没有历史申诉的新状态；不允许给旧申诉事后虚构历史签名。不涉及真实教师身份认证或真人试验。
