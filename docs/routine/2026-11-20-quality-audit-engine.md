# 2026-11-20 — v0.5 命题质量独立检查器 / Quality audit engine

## 本次改动
- 新增 scripts/question_quality.py，可离线读取兼容 v1 的题库；检测同文题、归一化相似题、跨概念题族、开放题重复评分规则、过短解释、异常来源标记和证据缺失。
- 增加可选 arithmetic 数值见证：只用 Python AST + Fraction 检查加减乘除的有界有理数表达式是否与单选/短答键一致，并查找数值等价干扰项；不调用 eval、exec、模型或网络。
- 增加审核 attestations（--review）：必须绑定题库原始 SHA256，每题要求有独立审阅者确认来源、标准答案、课程范围、歧义、公平与评分标准；--strict 缺失审核即失败。注意：审核记录只是责任链，不构成自动真值认证。
- JSON 输出仅含检查计数、问题代码和题目 ID；默认不泄漏正确选项、题干、学生回答或主观题评语。
