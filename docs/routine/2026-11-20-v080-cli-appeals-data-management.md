# 2026-11-20 — v0.8.0 评分申诉与生命周期CLI贯通

## 本次修改
- scripts/qa.py 新生成作答记录时写入唯一 event_id，answer直接返回该ID；旧记录无需整体迁移，可使用event-index发起申诉并只为该条补ID。
- 新增 appeal-open/appeal-list/appeal-resolve，支持明确原因代码、待审理与结案状态、复核者确认、依据原评分标准修正分数，纠正后的分数被原始诊断/离线看板自动读取。只保存简洁审计字段，不留学生原答和审阅者自由文本。
- 新增 state-snapshots、state-export、state-delete；默认导出统计摘要，输出完整私人学习记录需要双重确认，删除必须明确输入DELETE-LOCAL。state-recover可指定快照ID，保持对旧.bak的兼容。
- 所有新写入、读取、删除与恢复仍由原系统 native lock 包裹，支持本地多进程安全。report新增待处理和已解决申诉计数，不泄漏学生原答。
