# 2026-11-21 — 严格模型审题的合成错误攻击测试

## 本次修改
- 新增tests/test_model_audit.py，覆盖默认全未通过、不同命题/审核身份的自声明、题库SHA256变更、模型独立答案与题库不符、数学等价的严格限制、九维审核任意项“uncertain/failed”、文字依据过短、遗留风险、三项干扰项缺失、人工rubric不完整。
- 课程模式校验来源SHA256、逐字引文、拒绝以original-example冒充教师课件；通识题库不得冒充已课程验证。生成模板默认blocked，CLI不覆写现有审阅表。
- 验证程序输出不会泄漏题干或答案；即使审阅表结构合格，也仅返回“已记录模型审核、可用于低风险练习”，不宣称实际语义正确、实名独立审阅或考试可靠性。
- 所有通过案例是**构造出来的合成审阅表**，不代表调用了大模型或真实老师验证了课程。
