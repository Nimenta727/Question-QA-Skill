# 2026-11-20 — v0.9.0 本地复核者能力凭据 / Local Reviewer Credentials

## 修改内容
- 新增 scripts/reviewer_credentials.py：管理员和审阅者使用32字节随机能力凭据，用户自行存放在0600本地秘密文件，登记簿仅保存随机salt与PBKDF2-HMAC-SHA256验证值，不保存明文密钥。
- 注册、添加审阅者、撤销与检查命令使用本地系统原生排他锁，管理员凭据必需；独立审阅者持凭据才能被认证为该登记ID，撤销后无法再次认证。
- 使用 constant-time HMAC比较，并限制审阅者ID字集、阻止已有身份复用、拒绝符号链接和POSIX上组/公共可读的凭据文件。Windows文件权限需另行使用OS访问控制管理。
- **能力凭据不证明真人姓名、专业资格、学校任命或实际独立盲评**。只有管理员真实核验线下身份并保护凭据时，注册簿才有相应意义；本模块不声称身份KYC。
- 不收集学生原答案、不调用外网API；密钥不能上传GitHub或进入发行包。
