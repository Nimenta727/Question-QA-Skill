# 2026-11-20 — v0.7 可控数学等价验证 / Bounded math equivalence

## 修改内容
- 新增 scripts/math_equivalence.py：使用 Python AST白名单 + Fraction 精确有理数多项式计算，不运行eval、exec、任意函数或用户脚本；明确限制表达式长度、AST节点、递归深度、多项式项数/总次数、系数位数与指数。
- qa.py 短答题可显式添加 answer_equivalence:{kind:rational} 或 {kind:polynomial,variables:[x]}（也支持y和[x,y]）。只对**出题者明确启用且答案本身可解析**的短答进行语义一致性比较；其他旧题保持原有字符串匹配判分，数学判分有独立method。
- 无法安全解释的输入不擅自判零分而保留待答题并要求复核；既有 --review-equivalent --reason 手动审阅仍可使用。数学数值不等价的有效表达式才记录错误；不能处理单位、变量定义域、非多项式、分母含变量、证明题和自然语言。
- 演示题库 ALG-003 的确切数值短答显式启用 rational 规则；其他题不作自动扩权，不改变此前诊断的权重和外部评测结果。
