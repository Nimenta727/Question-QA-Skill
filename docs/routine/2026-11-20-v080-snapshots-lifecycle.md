# 2026-11-20 — v0.8.0 学习记录生命周期与多版本快照

## 本次修改
- 扩展 scripts/state_store.py：每次成功写入前留存旧有效状态的时间+随机ID快照，默认最多5份，同时保留旧版.bak供兼容；只在新状态提交后修剪快照，防止恢复不可用。
- 支持列出所有受控快照（仅校验摘要/历史数量）、按快照ID或旧.bak恢复；恢复前若当前状态有效则额外留存一个可回退快照。
- 数据导出：默认只输出知识点次数/平均已观测成绩和申诉状态汇总；明确同意时可以输出完整私有state供个人备份，不允许静默覆盖目标文件，禁止把导出写入源状态/备份/快照位置。
- 数据删除：仅删除该state、该state.bak与自动生成的受控快照，保留文件锁侧车，避免其他进程在锁未释放时建立第二套锁。警示这只是普通文件unlink，**不是保证不可恢复的安全擦除**，无法删除外部备份或终端日志。
- 保留原来的fcntl/msvcrt本地排他锁；这是本地文件管理，不是跨云/网络盘分布式事务。
