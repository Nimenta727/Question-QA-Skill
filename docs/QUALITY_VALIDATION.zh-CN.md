## 必须分开的三个问题

A. AI 命题是否真的正确、有课程依据？B. 审题模型能否找出关键错误、又不过度误报？C. 自适应追问是否比固定题序提供更多**可核验**的理解证据？

- **资料**：仅使用获准使用的课件片段，记录章节/页码、目标知识断言、先修关系、认知层次和人类核验解答；无课件只能标注通用练习。
- **独立题族**：用不同表征和推理任务分组，不把换数字当独立证据；先冻结最终盲测数据，再进行调整。
- **缺陷集**：覆盖错答案、第二正确选项、合理等价解、漏前提、假引用、干扰项/评分rubric不完整、认知层次不符、不公平表述、重复题族，同时保留真正正确的对照题。
- **可追溯**：记录来源版本、题目哈希、模型/版本、审核输入、盲解证据、时间及真人分歧裁决；不公开真实学生记录或未经授权的课件。

## 需要统计的指标

| 维度 | 分子 / 分母及指标 | 需要显式报告的失败 |
| --- | --- | --- |
| 命题正确性 | 人类核验正确题 / 审题总数，并分类缺陷 | 错解、多解、无依据引用 |
| 审题召回率 | 成功拦截缺陷题 / 独立标注缺陷题 | 漏检：错误题被放行 |
| 审题特异度 | 正确放行好题 / 独立标注好题 | 误报：合格题被拒 |
| 来源可核验率 | 来源准确且有授权的断言 / 全部核对断言 | 伪造课件页码、哈希不符 |
| 追问针对性 | 下一题确实核验关键缺口的轮次 / 有效轮次 | 猜对宣称掌握、错一道就给误区贴标签 |
| 评分公平与可解释 | 独立评阅者分项评分及分歧 | 无理排斥等价解、语言负担 |
| 使用成本 | 每有效学习轮的实测 Token、模型调用与延迟 | 只凭ZIP大小宣称Token节省 |

诊断场景至少覆盖：错题但原因未知、提示后正确、猜对、部分正确、解释充分并能迁移、答案歧义、课件缺失、题库耗尽、学生主动停止。**固定题序对照、评价标准和阈值应预先固定**，不能看过测试结果再改口径。

## 验收硬门槛与合规

- CI 全绿只能说明软件测试通过，不能替代命题正确率与教学验证。
- 没有明确样本量、分子/分母、独立标准、置信区间及实验设置时，不能对外声称准确率或教学提升。
- 审核 JSON 验证通过不是独立语义证明；任何关键答题/来源风险未解决时必须拦截或重审。
- 正式考试需专业真人审核；涉及真实学生，必须由适当负责方处理授权、知情同意、适用监护同意与数据保护。
- 旧 FORGET-SE、ASSISTments2015 的结果不得再作为新模型参数选择后的“全新独立测试”。

## 计划交付

1. 冻结题目缺陷分类和评测清单，使用合成或许可素材。
2. 获取盲审标签、独立评阅及分歧裁决，并隔离留出集。
3. 真正运行命题模型和审核模型，保存漏检、误报、修订与再次审核轨迹。
4. 与固定顺序、简单历史成绩基线比较诊断追问。
5. 公布聚合统计、不确定性、成本与失败项；仅在有证据时调整产品能力声明。
